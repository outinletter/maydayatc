# 빌드 12 심사 신청 전 검토 자료

작성일: 2026년 10월 22일

이 자료는 보완 내용과 제출 준비 상태를 정리한 문서입니다. 사용자 요청에 따라 Apple에 답변을 전송하거나 심사를 신청하지 않습니다.

## 보완 취지

기존 영상 목록 중심의 진입 화면에 역할별 학습 진입점을 추가했습니다. 개발자인 조종사가 직접 기획한 항공영어 학습 앱이라는 목적을 명확하게 하고, 조종사와 관제사가 각각 대화를 읽고 답을 선택한 뒤 해설과 복습으로 이어지는 기능을 제공합니다.

## 실제 구현한 변경

1. 설정에서 Pilot 또는 Controller를 선택하고 기기에 저장합니다.
2. 홈의 역할별 연습 항목에서 영상 재생 없이 학습 레슨 목록으로 진입합니다.
3. 선택한 역할의 대화 응답을 가려서 연습하거나, 두 예제 중 해당 레슨의 다음 발화를 고릅니다.
4. 현재 번들 15개 레슨에서 두 역할을 합쳐 73개 문항을 구성합니다. 문항 수는 콘텐츠 업데이트 시 달라질 수 있습니다.
5. 정답과 오답을 문구와 아이콘으로 구분하고, 정답으로 연결되는 원문 응답과 설명을 제시합니다.
6. 오답을 역할별로 기기에 저장하고 오답이 있는 레슨만 골라 다시 연습할 수 있습니다. 새 회차를 시작할 수 있습니다.
7. 대화 내용이 변경되면 기존 내용의 정답 기록이 새 내용에 잘못 적용되지 않도록 문항 식별자를 분리합니다.
8. 설정에서 역할별 풀이 현황을 확인하고 로컬 데이터 삭제 시 역할 선택과 문항 기록도 삭제합니다.
9. 정기 콘텐츠 수집 결과는 관리자 검토용 후보 파일로 저장합니다. 개발자가 검토하고 승인한 변경을 main에 반영해야 사용자가 받을 수 있습니다.

현재 문항은 가상 대화의 순서와 응답을 확인하는 독해 연습입니다. 실제 비행 상황에서 사용할 최선의 관제 지시를 판정하거나 공식 자격·숙련도를 평가하지 않습니다. 새 자료 전체가 이미 전문가 검수를 마쳤다고 주장하지 않습니다.

## 심사에 전달할 사실

- 대상 사용자는 조종사와 관제사입니다.
- 개발자 본인이 조종사이며 직접 필요성을 느끼고 기획·개발했습니다.
- 상용 앱 템플릿이나 앱 생성 서비스를 사용하지 않았고 제작 의뢰도 없었습니다.
- 같은 개발자 계정의 다른 앱과 자체 코드·이미지·학습 자료를 공유하지 않습니다.
- 외부 영상은 출처를 표시한 링크이며 독립된 가상 연습 자료와 구분합니다.
- TestFlight 및 외부 베타 테스트를 실시하지 않았습니다. 개발 중 피드백을 외부 베타 피드백이라고 쓰지 않습니다.

## 확인한 검증

- 콘텐츠 스키마와 양쪽 JSON 파일 일치 검사 통과.
- 콘텐츠 수집·게시 관련 Python 테스트 5개 통과.
- Swift 콘텐츠 디코딩과 대화 파서 테스트 통과.
- 73개 역할별 문항의 선택지·정답·식별자 검증 통과.
- 서명된 iPhone용 Release 빌드 성공. 버전 1.0, 빌드 12 확인.
- 최종 아카이브 생성 및 App Store Connect 업로드 성공: outputs/build12/MaydayATC12-final.xcarchive.
- 아이폰에 최종 Release 빌드 12 설치 완료.
- 실기기 UI 테스트 통과: Engine Failure 레슨의 조종사·관제사 역할, 정답·오답 피드백, 역할 설정과 오답 기록의 재실행 후 유지, 복습 목록 필터 활성화 확인. 테스트 1개, 실패 0개, 건너뜀 0개.
- 실기기 원본 캡처 6장 촬영·검토 후 스토어에 업로드. 기존 앱 미리보기 영상은 유지.
- 스토어 설명과 심사 메모를 App Store Connect에 저장.
- GitHub main에 구현 커밋 9c0bf16 반영.

## 신청 전 남아 있는 단계

- Apple 빌드 처리 완료 후 빌드 12를 버전 1.0에 연결하고 저장.
- 로컬 데이터 삭제는 기존 사용자 기록을 보존하기 위해 실기기에서 실행하지 않았음. 삭제 동작은 코드 검토 범위이며 UI 테스트 통과 항목에 포함하지 않음.
- 사용자가 검토한 후 심사 답변 전송 및 재신청. 현재는 전송·재신청하지 않음.
