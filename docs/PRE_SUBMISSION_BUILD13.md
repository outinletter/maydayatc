# 빌드 13 심사 신청 전 준비 상태

빌드 12의 학습 기능과 검증 내역은 PRE_SUBMISSION_BUILD12.md에 기록되어 있습니다. 빌드 13은 사용자 요청에 따라 각 응답을 펼친 후 다시 가리는 기능을 추가한 최종 후보입니다. 빌드 12는 수정 전 후보로 업로드되어 있으며 재신청에 사용하지 않습니다.

- 조종사·관제사 각각 Reveal 응답 버튼을 누르면 원문과 Hide 버튼을 표시합니다.
- 같은 위치의 Hide 버튼을 누르면 해당 응답만 다시 가려집니다.
- 두 역할에 대해 펼치기와 가리기를 두 번씩 반복하는 실기기 테스트가 통과했습니다.
- 기본 열람 화면과 퀴즈에는 새 가리기 버튼이 나타나지 않습니다.
- 빌드 12에서 촬영한 원본 스크린샷 6장은 변경되지 않은 홈·설정·퀴즈·해설·복습 화면을 보여주므로 유지합니다. 반복 가리기 기능 자체의 촬영본으로 주장하지 않습니다.
- APP_REVIEW_RESPONSE_4_3.md와 APP_STORE_METADATA_ROLE_PRACTICE.md에 최종 변경을 반영했습니다.

최종 Release 아카이브는 outputs/build12/MaydayATC13.xcarchive에 생성했습니다. 빌드 13의 아이폰 설치·실행과 App Store Connect 업로드가 성공했습니다. Apple의 빌드 처리가 완료되면 버전 1.0의 연결 빌드를 13으로 저장해야 합니다. 스토어 설명과 심사 메모는 반복 가리기를 포함한 내용으로 저장했습니다.

심사 답변 전송과 재신청은 사용자 요청에 따라 진행하지 않습니다. 빌드 12 및 거절된 빌드 11을 최종 보완본으로 재제출하지 않습니다.
