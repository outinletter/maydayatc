# 빌드 14: 예문별 해설 비교

최신 제출 준비 후보는 버전 1.0 빌드 14입니다. 기존 빌드 12·13의 기능과 검증 내역은 각각의 준비 문서에 보존합니다.

- 예문을 선택한 후에도 A와 B를 자유롭게 바꿔 선택할 수 있습니다.
- 정답 예문은 선행 메시지와 다음 응답을 연결해 설명합니다.
- 오답 예문은 선택한 문장이 다른 발화 순서에 속한다는 점과 해당 위치의 실제 다음 응답을 설명합니다.
- 정답 해설은 민트색, 오답 해설은 하늘색으로 표시하며 문구와 아이콘으로도 구분합니다.
- 한 회차의 최초 답변만 풀이 기록과 오답 복습에 반영합니다. 해설 비교는 풀이 횟수를 늘리거나 최초 결과를 덮어쓰지 않습니다. 새 회차를 시작하면 다시 답할 수 있습니다.
- 기존 응답 펼치기·다시 가리기 기능은 유지합니다.

## 검증

73개 문항의 선택지별 설명 검사와 기존 콘텐츠·파서 검사가 통과했습니다. 실제 iPhone 16 Pro의 Engine Failure 레슨에서 오답 선택, 정답 예문으로 전환, 해설 교체, 재실행 후 최초 오답 기록 유지 및 오답 필터를 검증한 UI 테스트가 통과했습니다. 실패 0개, 건너뜀 0개입니다. 첫 시도는 캡처 후 미리보기 화면의 터치 간섭으로 설정 화면에 진입하지 못했습니다. 캡처 후 앱을 재활성화한 재시도가 통과했습니다.

실기기 원본 화면 7장은 outputs/app-store-screenshots/iphone-release14에 보존했습니다. 정답·오답 설명 화면을 직접 확인했습니다. TestFlight 또는 외부 베타 테스트를 실시한 것으로 기재하지 않습니다.

Release 아카이브 생성, 아이폰 설치 및 실행이 완료됐습니다: outputs/build12/MaydayATC14.xcarchive. 2026년 10월 23일 빌드 14를 App Store Connect에 업로드했고 Apple 처리 상태는 제출 준비 완료입니다. 버전 1.0 draft는 빌드 14를 선택하고 저장했습니다. 제품 페이지 설명과 심사 메모를 빌드 14 내용으로 저장했으며, iPhone 중형 디스플레이 스크린샷 7장을 최신 원본으로 교체하고 기존 앱 미리보기 영상을 유지했습니다. 심사 회신은 문서로 준비되어 있으나 전송하지 않았고, 심사 업데이트 버튼도 누르지 않았습니다.
