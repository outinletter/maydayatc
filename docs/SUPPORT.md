# Mayday ATC Support

For app support, privacy questions, or learning-content corrections, email **outinaddvalue@gmail.com** or [open a GitHub issue](https://github.com/outinletter/maydayatc/issues).

Please include your app version, iOS version, and a description of the issue. For a video-link problem, include the video URL. Do not send passwords or sensitive personal information.

Mayday ATC is an independent aviation English practice aid. Lessons and saved items work offline. External YouTube videos and manual content updates require internet access. Conversations are fictional language exercises, not actual transcripts or operational guidance.

Use Settings → Update content to download the latest published video list and exercises. Use Settings → Delete local data to remove downloaded lessons, saved items, and progress.
